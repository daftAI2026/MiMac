# 准备调研

- 先查已有源码、模型、取证和实验，再决定是否重新获取。共享不变的参考版本、依赖与大资源；确需修改时隔离候选，只保留可核验的差异和版本关系，不能改坏共享原件。
- 确定本轮问题、成功判据、必要输入和输出位置。沿用现有任务记录；缺少实验说明时才使用 [实验记录模板](../assets/experiment.md)，不要另建重复账本。
- 把唯一参考源码、共享输入、实验代码、可丢弃临时输出区分存放。兼容已有目录和运行器，不为统一目录名搬动旧实验。输入、资源与结果路径显式传入并在动作前检查，不能依赖移动前的脚本位置。
- 大资源获取前查本地同版本/SHA和体积。必要模型、工具链及唯一 SDK 保留一份可读原件；不能仅因有下载地址就清掉复现输入。
- 参考对象名称、链接、分析、实验输入和证据只进仓外与私人文档；公开仓仅维护通用方法，不记录调查对象或具体案例。
