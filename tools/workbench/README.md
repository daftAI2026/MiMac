# MiMac 本地工作台

开发入口，集中查看品牌、执行中的设计 token、组件布局样本与架构流程。工作台不进入 App 包，也不读取用户配置、麦克风或私人文档仓。

从项目根目录运行：

```sh
./script/workbench.sh
```

打开终端显示的 `http://127.0.0.1:4173`。`Ctrl+C` 结束服务。需要 Node.js 20+ 和项目 Go 工具链；可使用 `MIMAC_GO=/path/to/go`、`MIMAC_WORKBENCH_PORT=4174`。首次运行按锁文件安装开发依赖。`./script/workbench.sh --build` 只构建，不监听端口。

数值和浅深色来自 Go AST 对 `cmd/mimac/design.go` 的导出。图表以 `diagrams/*.mmd` 为源，清单记录对应产品源码；修改流程时一并更新。构建使用固定版本 Pele 生成 SVG，浏览器不加载图表引擎或 CDN。每个源码入口链接构建时的只读快照，内容哈希在 `dist/data.json` 中。源码变动后重新运行构建。

语音入口图区分当前可执行路径与未来适配要求：实线跟随现有实现，虚线部分不代表已支持的能力。工具启用、当前工具选择、动作执行和目标提交是不同步骤。

语音呈现图记录 Core 状态与当前会话电平如何到达可选悬浮语音条。MyGo 管理非激活窗口，siriglass 仅在已验证的系统版本加载；关闭显示不停止音频。厂商语音条接管和完整 Siri 前景/业务语义仍用虚线表示，本地排空不能代替第三方工具的提交回执。

共享 PCM 观测图记录同一读取点上的可选频谱分析、会话隔离与清理。频谱测量可供经过 MiMac 音频通道的工具复用；当前测量参数和原版 Siri 的归一化合同分别标注，不把原生接口接受参数等同于视觉验收。

组件页是 token 和布局的 Web 样本，原生菜单、SwiftUI Form、系统绿色及 CoreAnimation 效果以实际 App 为准。它不会触发产品功能。正式设计契约见项目根目录 `DESIGN.md`。

## 原生页面预览

打开工作台的“页面预览”，查看设备、按键映射、语音工具、插件、通用、关于六个设置页的真实窗口截图。截图包含原生控件和窗口装饰，点击图片可查看原图；采集信息记录时间、像素尺寸、窗口尺寸和采集时磁盘程序 SHA256。当前配置截图不代表其他明暗模式、字号、错误状态或菜单已验收。

更新截图时先打开现有固定 MiMac App 的设置窗口，再运行：

```sh
./script/capture_workbench.swift --bundle /absolute/path/to/MiMac.app
./script/workbench.sh --build
```

脚本需要当前 runner 已有辅助功能和屏幕录制权限，仅截取这一个 App 窗口，不录桌面或音频。它短暂激活并设为主窗口，依次切换侧栏、核对页面标题并等待像素稳定，然后恢复原页面与先前的前台应用；不点击功能开关。导航历史会留下这次页面切换，不恢复控件内部的光标或选区。用户中途切走前台时停止，不反复抢回窗口。六页全部成功后才更新 `~/Library/Caches/MiMac/workbench-captures/latest.json`；缺失本机截图时，工作台仍可独立构建并显示采集入口。截图缓存不进入产品仓和 App 包；私人归档不成为工作台依赖。

## 架构画布

图形仍由锁定版本的 Pele 从 Mermaid 生成 SVG。画布支持拖拽平移、鼠标滚轮缩放、触控板双指平移及捏合缩放；也可使用缩放按钮、“适应视图”和“100%”。聚焦画布后按 `+`、`-`、`0`；`0` 恢复原始比例。变换只影响查看，不修改图形源码，导出保留原始图形尺寸。修改实现或验收边界时同步 `diagrams/*.mmd` 与 `diagrams/manifest.json`，再重新构建工作台。
