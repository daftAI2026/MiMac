# MiMac 本地工作台

开发入口，集中查看品牌、执行中的设计 token、组件布局样本与架构流程。工作台不进入 App 包，也不读取用户配置、麦克风或私人文档仓。

从项目根目录运行：

```sh
./script/workbench.sh
```

打开终端显示的 `http://127.0.0.1:4173`。`Ctrl+C` 结束服务。需要 Node.js 20+ 和项目 Go 工具链；可使用 `MIMAC_GO=/path/to/go`、`MIMAC_WORKBENCH_PORT=4174`。首次运行按锁文件安装开发依赖。`./script/workbench.sh --build` 只构建，不监听端口。

数值和浅深色来自 Go AST 对 `cmd/mimac/design.go` 的导出。图表以 `diagrams/*.mmd` 为源，清单记录对应产品源码；修改流程时一并更新。构建使用固定版本 Pele 生成 SVG，浏览器不加载图表引擎或 CDN。每个源码入口链接构建时的只读快照，内容哈希在 `dist/data.json` 中。源码变动后重新运行构建。

语音入口图区分当前可执行路径与未来适配要求：实线跟随现有实现，虚线部分不代表已支持的能力。工具启用、当前工具选择、动作执行和目标提交是不同步骤。

语音呈现图记录 Core 状态与当前会话电平如何到达可选悬浮语音条。MyGo 管理非激活窗口，siriglass 仅在已验证的系统版本加载；关闭显示不停止音频。厂商语音条接管和完整 Siri 前景/业务语义仍用虚线表示，本地排空不能代替第三方工具的提交回执。

共享 PCM 观测图记录同一读取点上的可选频谱分析、会话隔离与清理。频谱测量可供经过 MiMac 音频通道的工具复用；当前测量参数和原版 Siri 的归一化合同分别标注，不把原生接口接受参数等同于视觉验收。

组件页是 token 和布局的 Web 样本，原生菜单、SwiftUI Form、系统绿色及 CoreAnimation 效果以实际 App 为准。它不会触发产品功能。正式设计契约见项目根目录 `DESIGN.md`。

Pele 为 MIT 授权：[obsidianmd/pele](https://github.com/obsidianmd/pele)。构建输出保留其许可证。

## 原生页面预览

打开工作台的“页面预览”，查看设备、按键映射、语音工具、插件、通用、关于六个设置页的真实窗口截图。截图包含原生控件和窗口装饰，点击图片可查看原图；采集信息记录时间、像素尺寸、窗口尺寸和采集时磁盘程序 SHA256。页面预览明确标注为静态截图，不代表权限、连接、错误或语音动态状态已验收。

可选的六配置矩阵索引放在截图缓存目录的 `matrix-index.json`，根对象使用 `schema: 1` 和 `configurations` 数组，包含浅色/深色各自的小号、标准字号和大号配置。有有效矩阵时默认选择浅色标准字号；单一 `latest.json` 图库仍可从选择器中打开。索引引用同目录下的捕获 UUID；截图仍由各 UUID 目录中的 `manifest.json` 描述。构建会逐项校验配置唯一性、固定应用身份、窗口和六页集合，以及每张 PNG 的 SHA256 与尺寸；不依赖私人文档或研究目录。没有矩阵索引时，页面维持原有单一最新图库行为。

更新截图时先打开现有固定 MiMac App 的设置窗口，再运行：

```sh
./script/capture_workbench.swift --bundle /absolute/path/to/MiMac.app
./script/workbench.sh --build
```

脚本需要当前 runner 已有辅助功能和屏幕录制权限，仅截取这一个 App 窗口，不录桌面或音频。它短暂激活并设为主窗口，依次切换侧栏、核对页面标题并等待像素稳定，然后恢复原页面与先前的前台应用；不点击功能开关。导航历史会留下这次页面切换，不恢复控件内部的光标或选区。用户中途切走前台时停止，不反复抢回窗口。六页全部成功后才更新 `~/Library/Caches/MiMac/workbench-captures/latest.json`；缺失本机截图时，工作台仍可独立构建并显示采集入口。截图缓存不进入产品仓和 App 包；私人归档不成为工作台依赖。

## 交互状态预览

“截图配置”中的“交互状态”查看真实菜单栏菜单和普通按键的预设菜单。沿用页面截图的原图、下载和源码入口；菜单按实际点尺寸显示，包含父窗口时保留系统原图范围，不放大小菜单。

先用 `script/verify_app_bundle.py` 核验现有正式包，再在该固定 App 的设置窗口打开时运行：

```sh
./script/capture_workbench_states.swift --bundle /absolute/path/to/MiMac.app --expected-sha EXPECTED_EXECUTABLE_SHA256
./script/workbench.sh --build
```

`EXPECTED_EXECUTABLE_SHA256` 使用已核验包中 `MacOS/MiMac` 的值。脚本只展开菜单并取消，不选择菜单项，不启用遥控器或收音；需要已有辅助功能和屏幕录制权限，不主动申请权限。它恢复原页面和此前前台，但菜单打开会改变当前选中行和导航历史。用户切走时停止，不抢回前台。

完整两场景通过后才更新 `~/Library/Caches/MiMac/workbench-states/latest.json`。状态图与六页矩阵使用独立合同，验证 PNG、完整应用和采集脚本身份、配置未变及菜单关闭标记，再发布到工作台。缓存缺失时仍可构建；实际权限拒绝、错误、连接和语音会话需要各自场景证据，这两张菜单图不能代替它们。

## 架构画布

图形仍由锁定版本的 Pele 从 Mermaid 生成 SVG。画布高度由浏览器窗口确定，在同一窗口尺寸下保持固定；缩放只改变内部图形。画布支持拖拽平移、鼠标滚轮缩放、触控板双指平移及捏合缩放；也可使用缩放按钮、“适应视图”和“100%”。聚焦画布后按 `+`、`-`、`0`；`0` 恢复原始比例。变换只影响查看，不修改图形源码，导出保留原始图形尺寸。修改实现或验收边界时同步 `diagrams/*.mmd` 与 `diagrams/manifest.json`，再重新构建工作台。
