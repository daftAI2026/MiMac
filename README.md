# MiMac

macOS 小米遥控器桥接应用，连接现有语音输入工具，保留遥控器各按钮的自定义映射。首个硬件目标为小米蓝牙遥控器 2 Pro。

当前为开发预览：MyGo 承担菜单栏、设置窗口与主线程；设备和按键输出使用编译期插件。已实测 RC003 按键监听，提供小米遥控器外观与按钮热点、按键映射、快捷键录入及按设备保存配置。通用设置提供登录时启动、Dock 显示、系统／浅色／深色外观和文字大小；设置即时生效。关闭设置窗口后继续运行。遥控器默认未启用；启用后接管语音键，普通按钮的自定义映射额外发送快捷键，其他原始按键仍由 macOS 处理。语音键只关联所选工具的已验证动作，没有工具时显示待设置且不启动麦克风；停用和退出时恢复设备映射。第三方语音工具闭环仍待验证。豆包输入法、Typeless、ChatGPT 各有独立的配置发现插件，在插件页启用后自动只读查找，并在语音工具页单选当前工具；已验证格式的快捷键可从预设菜单复制到映射。未找到或未支持的配置会明确显示，遥控器音频尚未接通。

音频会话与定向输出已通过指定设备上的合成音频验收，支持 8/16 kHz 单声道 PCM、系统格式转换、结束排空与取消清理。该能力默认不启动，尚未连接遥控器音频源或验证第三方语音识别结果。

开发需要 macOS、Xcode Command Line Tools（含 Swift 编译器）、Python 3 和 Go 1.27.1+。构建脚本同时编译原生设置视图；窗口与事件循环仍由 MyGo 承担。

```sh
./script/build_and_run.sh
./script/build_and_run.sh --verify
go test ./...
```

可用 `MIMAC_GO=/path/to/go` 指定工具链，`MIMAC_SIGN_IDENTITY` 指定本机已有签名身份。`--verify` 执行有界的设置窗口启动与退出检查。

图标源文件为 `Assets/Brand/MiMac.icon`，可用 `./script/export_icon.sh` 更新同源 PNG。有 Xcode 时 MyGo 编译原生图标；否则使用 PNG。
