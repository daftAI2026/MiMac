# MiMac

独立的 macOS 小米遥控器桥接项目，目前处于源码研究、状态机设计和技术验证阶段。

- 保留遥控器各按钮的自定义映射。
- 配合用户正在使用的语音输入工具，按实际配置适配动作与快捷键。
- 使用遥控器麦克风时，提供通用音频桥接。
- 自有语音 API 暂不实现。

这是新项目，不继承任何参考项目的目录、发布体系或附加功能。
当前技术栈建议为 Swift、SwiftUI 与少量 AppKit；设备、按钮与会话、工具配置、音频输出各自负责自己的状态和生命周期。
MyGo 已完成独立宿主试验，保留为候选。技术建议仍待实际遥控器与语音工具的集成验证。
参考源码、研究记录及试验保存在项目目录外。
