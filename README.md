# MiMac

独立的 macOS 小米遥控器桥接项目，目前开始最小版本开发，源码研究与技术验证继续并行。

- 以小米 Pro 2 为首个验证目标，保留遥控器各按钮的自定义映射。
- 配合用户正在使用的语音输入工具，也研究 Codex 等编程 Agent 的内置语音入口。
- 按实际配置适配多个动作、快捷键及其作用域，分别处理开始、结束、取消与目标自身的提交策略。
- 使用遥控器麦克风时，提供通用音频桥接。
- 自有语音 API 暂不实现。

这是新项目，不继承任何参考项目的目录、发布体系或附加功能。
当前优先验证用 MyGo 承担桌面宿主：菜单栏、窗口、事件循环和主线程调度直接使用框架能力；核心协调与设备、目标工具、音频适配模块分开。以真实常驻资源与原生接口接入成本验证选择，不预先宣称性能最优。
音频输出保留公共 Process Tap/Aggregate、既有 loopback 与独立 HAL 的比较边界。研究程序已在独立进程间收到合成 PCM；频率测量修正后的完整验收、现成语音工具兼容仍待验证。
当前已加入 MyGo 菜单栏宿主与独立 Go 状态核心，尚未接入真实设备、系统按键或音频。首版插件优先使用编译期模块，不引入动态脚本和插件市场。
首个只读配置模块为 Typeless：仅从显式指定的设置文件读取已核实的动作数组与麦克风设备 ID；不扫描用户目录、不填入厂商默认值、不写回配置。设置窗口可显式选择 JSON 并查看读取结果；尚未接入实际动作发送。
参考源码、研究记录及试验保存在项目目录外。

开发需要 macOS、Python 3 和 Go 1.27.1+。运行 `./script/build_and_run.sh` 构建并启动菜单栏应用；`--verify` 执行有界的设置窗口启动退出检查。可用 `MIMAC_GO=/path/to/go` 指定工具链。核心行为测试：`go test ./internal/bridge`。

用户提供的原图已接入设置窗口、模板菜单栏图标和 App 的 ICNS 图标。当前是开发预览；Icon Composer 玻璃图标尚未制作。`--host-capture` 仅在显式指定路径时导出应用自身的内容截图，不使用桌面录屏；已有目标文件会被拒绝覆盖。
