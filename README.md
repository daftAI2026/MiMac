# MiMac

独立的 macOS 小米遥控器桥接项目，目前处于源码研究、状态机设计和技术验证阶段。

- 以小米 Pro 2 为首个验证目标，保留遥控器各按钮的自定义映射。
- 配合用户正在使用的语音输入工具，也研究 Codex 等编程 Agent 的内置语音入口。
- 按实际配置适配多个动作、快捷键及其作用域，分别处理开始、结束、取消与目标自身的提交策略。
- 使用遥控器麦克风时，提供通用音频桥接。
- 自有语音 API 暂不实现。

这是新项目，不继承任何参考项目的目录、发布体系或附加功能。
当前优先验证用 MyGo 承担桌面宿主：菜单栏、窗口、事件循环和主线程调度直接使用框架能力；核心协调与设备、目标工具、音频适配模块分开。以真实常驻资源与原生接口接入成本验证选择，不预先宣称性能最优。
音频输出保留公共 Process Tap/Aggregate、既有 loopback 与独立 HAL 的比较边界。公共设备元数据探针已通过，实际音频仍待验证。
MyGo 已完成独立宿主试验；纯状态模型也已有隔离验证。方案收敛后开始最小版本开发，源码深读与隔离音频试验继续并行。首版插件优先使用编译期模块，不引入动态脚本和插件市场。
参考源码、研究记录及试验保存在项目目录外。
