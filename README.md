# MiMac

macOS 小米遥控器桥接应用，连接现有语音输入工具，保留遥控器各按钮的自定义映射。首个硬件目标为小米蓝牙遥控器 2 Pro。

当前为开发预览：MyGo 承担菜单栏、设置窗口与主线程；设备和按键输出使用编译期插件。已实测 RC003 按键监听，提供小米遥控器外观与按钮热点、按键映射、快捷键录入及按设备保存配置。通用设置提供登录时启动、Dock 显示、系统／浅色／深色外观和文字大小；设置即时生效。关闭设置窗口后继续运行。遥控器默认未启用；启用后接管语音键，普通按钮的自定义映射额外发送快捷键，其他原始按键仍由 macOS 处理。语音键只关联所选工具的已验证动作，没有工具时提示启用语音插件且不启动麦克风；停用和退出时恢复设备映射。豆包的真实遥控器听写已在可选音频入口通过验收，其他目标仍待验证。豆包输入法、Typeless、微信输入法、闪电说和 ChatGPT 各有独立的配置发现插件，在插件页启用后自动只读查找，并在语音工具页单选当前工具；已验证格式的快捷键可从预设菜单复制到映射。未找到或未支持的配置会明确显示。

音频会话与定向输出已通过指定设备上的合成音频验收，支持 8/16 kHz 单声道 PCM、系统格式转换、结束排空与取消清理。该能力默认不启动。可选兼容端点已通过豆包 1.0.2 的合成语音及小米遥控器真实听写验收，包含连续会话和 AirPods 连接后的使用。该路径不更改系统默认输入或输出；外部中断、睡眠唤醒和其他目标仍待验证。

微信输入法的 Fn 按住说话动作已接入共享音频桥，选择工具时会切换系统输入法。已通过合成语音识别、冷启动与连续重开验收，使用微信自身的输入设备偏好接口，不更改系统默认音频设备。原版 Esc 会结束并提交，暂不提供撤销承诺；真实遥控器输入仍待验收。

Apple 语音识别是独立的可选插件，使用 macOS 26+ 的本机 SpeechTranscriber，当前提供简体中文。缺少模型时可在工具选项内下载。小米 PCM 直接交给识别器，不依赖音频兼容组件；文字写入前复核按下时的输入框与选区，不自动提交。两轮真实遥控器连续听写已在原生文本框通过，合成语音、取消重开及已提供辅助功能焦点的浏览器控件已验证；浏览器事件输入暂不支持多行或控制字符。默认浏览器的首次焦点发现和更多应用输入框仍待验收。

开发需要 macOS、含 macOS 26+ SDK 的 Xcode Command Line Tools（含 Swift 编译器）、Python 3 和 Go 1.27.1+。App 最低系统版本仍为 macOS 14.2，Apple 识别按系统能力启用。构建脚本同时编译原生设置视图；窗口与事件循环仍由 MyGo 承担。

```sh
./script/build_and_run.sh
./script/build_and_run.sh --verify
go test ./...
```

可用 `MIMAC_GO=/path/to/go` 指定工具链，`MIMAC_SIGN_IDENTITY` 指定本机已有签名身份。`--verify` 执行有界的设置窗口启动与退出检查。

可选音频兼容组件使用 macOS HAL 和固定版本的 libASPL，独立于普通 App 构建。运行 `python3 script/build_audio_compat.py --package` 可构建、测试并生成本机验收安装包；脚本不会安装组件或重启音频服务。已安装并验证组件的开发环境可用 `./script/build_and_run.sh run -- --audio-backend mimac-compat --show-settings` 验收小米到所选兼容工具的接线；仍需在 App 内启用遥控器和相应语音插件。此入口不安装组件、不更改系统默认音频设备。

图标源文件为 `Assets/Brand/MiMac.icon`，可用 `./script/export_icon.sh` 更新同源 PNG。有 Xcode 时 MyGo 编译原生图标；否则使用 PNG。

本地开发工作台集中查看品牌、设计 token、组件状态及架构流程。运行 `./script/workbench.sh`，打开终端显示的本地地址；需要 Node.js 20+，不参与 App 构建。详见 [工作台入口](tools/workbench/README.md)。
