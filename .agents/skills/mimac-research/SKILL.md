# MiMac 调研与实验收尾

适用范围仅为当前 MiMac 调研任务。先读项目 AGENTS.md、其中指定的私人文档入口、当前任务与相关经验；使用已有结论和后来已验结果，避免重做已完成的研究。此 skill 不授予额外删除、安装或发布权限；沿用用户已授权的具体范围，不为同一操作反复确认。

## 开始前

- 先查已有源码、模型、取证和实验，再决定是否重新获取。共享不变的参考版本、依赖与大资源；确需修改时隔离候选，只保留可核验的差异和版本关系，不能改坏共享原件。
- 确定本轮问题、成功判据、必要输入和输出位置。沿用现有任务记录；缺少实验说明时才使用 [实验记录模板](assets/experiment.md)，不要另建重复账本。
- 把唯一参考源码、共享输入、实验代码、可丢弃临时输出区分存放。兼容已有目录和运行器，不为统一目录名搬动旧实验。输入、资源与结果路径显式传入并在动作前检查，不能依赖移动前的脚本位置。
- 大资源获取前查本地同版本/SHA和体积。必要模型、工具链及唯一 SDK 保留一份可读原件；不能仅因有下载地址就清掉复现输入。
- 参考对象名称、链接、分析、实验输入和证据只进仓外与私人文档；公开仓仅维护通用方法，不记录调查对象或具体案例。

## 实验与取证

复用项目已有身份与验收记录，绑定实际源码、运行器、依赖、工具链、输入和程序身份。记录真实运行命令、结果位置和失败阶段；构建成功不代替行为通过。涉及当前 App、硬件、权限或音频时执行项目既有 SOP，不在这里另造一套流程。

围绕当前问题取证：保留关键动作、完整关键流程和必要对照，不默认无限录屏、逐帧导出或复制整个目录。日志按阶段保存，源数据和计数单独核对；不能用丢音频、截断必要证据或硬性容量上限解决磁盘增长。压缩原始字节需验证可还原与原 SHA 一致；视频裁切记录源区间，时序证据不加速、不随意抽帧。

每次得出结果就更新既有实验记录，区分通过、否决、未定和未运行；明确是否接入产品。**结果状态和保留价值分别判断：失败可能是重要反证，成功且未接入产品的实验也必须保留。**

## 收尾删除判据

| 材料 | 处理 |
|---|---|
| 实验代码、有效结果、复现命令与必要输入 | 保留。已完成或未接入产品都不是删除理由；已有完整同字节归档时可仅保留一份，确认输入和复现/恢复路径仍可定位，并给出可用入口。 |
| 模型、唯一 SDK、当前工具链、唯一参考版本 | 保留其被实验需要的内容与身份；不可按时间、体积或“可重新下载”删除。 |
| 当前运行 App、明确待验的固定程序、必要回归/回退与故障复现二进制 | 保留；即使有源码，也不能假定可重建为相同身份。 |
| 已结束实验的旧构建、编译中间物、字节码缓存、临时解包和帧导出 | 本任务所有、无进程占用、非待验身份且不承载唯一证据时可删；删除输出不连带删除实验代码和输入。 |
| 重复源码、依赖、资源或已归档的报告/日志 | 核验实际保留副本的内容及引用后删重复路径；若用补丁或生成配方代替副本，先重放并核对目标 SHA。 |
| 必要原始证据与有价值的失败输出 | 保留一份可用证据，不将历史完整性误写为当前功能已通过。无价值的过程输出（包括已确认没有取证用途的空文件）可直接删，不为清理再归档垃圾；零事件、零字节本身可能是重要证据。 |
| 活动 Git 仓及关联 worktree；参考源码内嵌的 App/框架 | 按实际用途保留，不能因 .git、.app、.test 后缀就判断可删。固定参考版本的无用 Git 历史可在版本溯源、源码和许可均保留且无活动关联时清理。 |
| 用途、归属、必要输入或唯一性尚不清楚 | 暂留该项并查明具体缺口，不因此阻塞其余明确可清项；不把所有旧文件永久标记为未知。 |

## 执行与核验

1. 列出本轮精确清理路径和理由，逐项检查任务归属、进程占用、活动 worktree、实际代码入口和待验计划。历史日志/任务快照出现路径不等于当前运行依赖；当前产品不用也不等于实验没有价值。
2. 核查保留链接的真实目标，也查是否有其他链接指向清理候选，包括被删目录外的链接。目标仍被需要就保留；合并副本时先在授权范围内修正引用并验证可读，不能为删除目标连带清掉保留的调用入口。没有证明整个目录都可删时，只删已确认的文件；不采用按日期、文件后缀或目录名批量删除。
3. 先把有用结论、必要证据、实验与复现关系写入私人文档并验证；遵守该知识库的发布约定。已有同字节归档直接复用，别再复制一份。涉及原件替代时验证真实内容、解压/重建 SHA，不能只相信索引里的 SHA。
4. 在已授权范围内执行明确可清的项。遇到必要输入、引用或身份核对失败就保留该项、记录原因；若请求明确涉及唯一有价值内容的不可逆删除，再确认这一具体取舍，不询问整个计划。
5. 删除后核对保留输入可读、软链无断链、相关仓库/worktree正常及被保护身份不变。只针对受影响的实验验证发现/准备或代表性自有输入；纯整理不重建日用 App、不改权限、不启动真人收音。
6. 报告清理范围、实验保留入口、实际核验和剩余缺口。目录 du、逻辑字节与 APFS 真实空闲分别表述，不把整理算作产品 CPU/内存优化或业务工作包完成。

不增加自动删除定时器、第二套归档服务或通用垃圾备份。每次调研按上述流程收尾，长期指令只保留可复用原则，案例与实验过程留私人文档。
